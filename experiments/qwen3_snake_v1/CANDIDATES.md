# Candidate selection before results

Selected **Qwen/Qwen3-4B-Instruct-2507**, revision `cdbee75f17c01a7cc42f958dc650907174af0554`. Its official model card identifies an Apache-2.0, 4B causal language model with non-thinking generation and llama.cpp support. Using that checkpoint avoids an additional reasoning-mode switch. It has no CLEF-compatible or verified Snake-specific decision head. The native chat template and constrained action generation are the supported interface chosen for this study. [Official card](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507), [pinned source files](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507/tree/cdbee75f17c01a7cc42f958dc650907174af0554).

The source configuration ties input embeddings and the lexical output projection. The source index includes the input embedding but no separate `lm_head.weight`. Keep this shared tensor in BF16 in every variant; its raw BF16 payload is 777,912,320 bytes. The remaining eligible tensors use the fixed backbone recipes. Verify actual GGUF types and tied-output behavior after conversion. Labels must say **Q4_K_M backbone + BF16 tied I/O** and **Q2_K backbone + BF16 tied I/O**, since these are not interchangeable with off-the-shelf files. The installed quantizer advertises `--token-embedding-type bf16` and `--leave-output-tensor`; their successful execution is still unverified. [Pinned configuration](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507/blob/cdbee75f17c01a7cc42f958dc650907174af0554/config.json).

**HuggingFaceTB/SmolLM3-3B** is the deferred alternative, revision `a07cc9a04f16550a088caea529712d1d335b0ac1`. It is an Apache-2.0 causal model from another family and supports a non-thinking mode. Its complete source snapshot is 6,167,865,576 bytes, versus Qwen's 8,060,917,568 bytes. It would offer a useful independent-family comparison but needs its own frozen template/mode protocol and seeds. It was not selected using any Snake scores. [Official card](https://huggingface.co/HuggingFaceTB/SmolLM3-3B), [pinned files](https://huggingface.co/HuggingFaceTB/SmolLM3-3B/tree/a07cc9a04f16550a088caea529712d1d335b0ac1).

The standard runtime can constrain generated text with a JSON schema; it does not thereby become a joint four-action decision head. The prompt explicitly describes the schema because grammar constraints alone are not injected into model-visible text. All four actions remain available, including unsafe choices. Native template, decoder and output tensor policy stay fixed within the sweep. [llama.cpp grammar documentation](https://github.com/ggml-org/llama.cpp/blob/f532be8facd5fb8bd292a35d6dc994277c33fcc5/grammars/README.md).

Feasibility is prospective. The Mac has 128 GiB unified memory and existing generation/quantization binaries; memory use and latency with these artifacts remain unmeasured. The Models external partition has adequate observed space under the [explicit reservation](storage-plan.json). A bounded cache inventory found no verified reusable source payload; unrelated installed models do not satisfy this pinned source. No weights, installations, conversions or inference were performed to select the candidate.
